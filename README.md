# Analizador de Notas

Programa que analiza un array de notas.

## ¿Qué hace?

1. Verifica si la nota más alta está repetida
2. Calcula el promedio
3. Dice si el promedio es aprobatorio (≥5)

## Ejemplo

Con las notas: `{5, 7, 3, 7, 2, 9, 7}`

Muestra:
```
NO
5.714285714285714
BIEN
```

## Cómo usarlo

```bash
javac AnalizadorNotas.java
java AnalizadorNotas
```
